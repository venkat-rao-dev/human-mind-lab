HTML Elements Used

Element Purpose
<header> Defines introductory content.
<nav> Contains navigation links.
<main> Contains the main page content.
<section> Groups related content.
<article> Represents independent content.
<table> Displays tabular data.
<form> Collects user input.
<details> Creates expandable information.
<progress> Displays task progress.
<meter> Displays a measurement.
