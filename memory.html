Memory Concepts

What is short-term memory?

Short-term memory refers to the temporary holding of information for a limited period.

What is long-term memory?

Long-term memory refers to information that can be retained for longer periods.

Why does repetition help learning?

Repeated exposure and active retrieval can support learning and memory.

Tips to Remember More

Try grouping words into small chunks, linking them into a short story, and testing yourself again after a break. Getting enough sleep also supports memory.
